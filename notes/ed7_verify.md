## 2. Per-item comments

### (a) Theorem 3.1 (no descent field inside K) — CORRECT
Word for word the argument of ed2_equals_2.tex, Theorem thm:caseA: inflation–restriction for K'/K with trivial action gives ker(res)=Hom(Z/2,Z/8)≅Z/2 generated by V²[f]=(0,0,f); truncation W_3→W_2 is a ring map commuting with ℘ and kills (0,0,f); so (s_0,s_1)_K descends to F_0, giving ed_k((s_0,s_1)_K)≤1, against ed_k((s_0,s_1)_K)=ed_k(τ_2)=2 (Lemma 3.2 + (F3)). The note correctly includes the purely transcendental step K=k(s_0,s_1)(s_2) that Corollary 1.3 skipped. No objection.

### (b) Lemma 4.2 — CORRECT
L⊗_K K' is a field because ker(H¹(K,Z/2)→H¹(L,Z/2))=Hom(Z/8,Z/2) is generated by [s_0] (F2, Lemma 1.2) and f∉{0,s_0}+℘K (Lemma 4.1). Hence the class of τ_gen⊗K' in H¹(K',Z/8) has order 8; β restricts to it, and ord_{F_0}(β) is a multiple of ord_{K'}(res β)=8, so ord_{F_0}(β)=8. The direction "order can only drop under base change" is used correctly. Witt identity: ghost components give 4(a_0,a_1,a_2)=(0,0,a_0⁴) (sympy: b_2=−81a_0⁴−6a_1²+4a_2+24a_0²a_1≡a_0⁴ mod 2). Then (0,0,β_0⁴)∉℘W_3(F_0) ⇒ β_0⁴∉℘F_0 (Fact 2.1(e),(d)) ⇒ β_0∉℘F_0 (β_0=℘c ⇒ β_0⁴=℘(c⁴); the note writes ℘(c²), a typo). Simpler: an order-8 class maps to a nonzero class under Z/8→Z/2, i.e. β_0∉℘F_0. Fine.

### (c) Lemma 5.1 — CORRECT
K⊆KF_0⊆K', [K':K]=2, F_0⊄K ⇒ KF_0=K'.

### (d) Corollary 5.2 — WRONG
The sentence "the compositum KF_0 is the function field K(B_K) of B×_kK" is false. K(B_K)=Frac(F_0⊗_kK) has trdeg_k 4 (=1+3) and trdeg_K 1; KF_0=K' has trdeg_k 3 and trdeg_K 0. Equality would require F_0 and K to be linearly disjoint over k, which is impossible since every t∈F_0∖k is quadratic over K. The next sentence "K(B_K)=K'=K(v_f) is rational over K" confuses the algebraic extension K[v]/(v²+v−f) with a rational function field K(v). So "B_K has genus 0 ⇒ g(B)=0 ⇒ F_0=k(t)" is unsupported.

Counterexample to the reasoning (a trdeg-1 subfield F_0⊆K', F_0⊄K, with KF_0=K', of positive genus): take f=s_2³+s_2² (f∉{0,s_0}+℘K, e.g. by Lemma 2.2 at the s_2-adic pole of order 3) and F_0:=k(s_2,v_f)⊂K'. Then F_0 is the function field of the supersingular elliptic curve y²+y=x³+x² (genus 1), F_0⊄K (v_f∉K), and KF_0=K(v_f)=K'. So the implication "KF_0=K' ⇒ F_0 rational" is false as a piece of logic. (Whether such F_0 carries the descent class is irrelevant to the validity of the implication, and the note gives no other reason.)

The second paragraph, "the rational function t∈K(v_f) generates K' over K; its degree as a map P¹_{v_f}→P¹ is [K':K(t)]=1, so it is birational", is meaningless: t is an element algebraic of degree 2 over K, and "P¹_{v_f}" (a projective line with coordinate v_f) does not exist inside K'; [K':K(t)]=1 says only K(t)=K'.

### (e) "t: P¹_{v_f}→P¹ birational", "unramified", "pole at the single point t⁻¹(u_0)" — meaningless
K'=K(v_f) is a finite (quadratic) extension of a trdeg-3 field over k. It is not the function field k(v_f) of a curve, K is not a field of "constants" in it (s_0∈K is not regular at every valuation of K'/k), and there is no point t⁻¹(u_0). The only meaningful reading is via discrete valuations v of K'/k; then "t has an odd pole at v" and "β_0(t)=β_0∘t has a pole at v" are statements about valuations of a 3-dimensional function field, and s_0 typically also has a pole there (see (f)). The statement of Prop 6.1 thus has no valid proof text.

### (f) Proposition 6.1 — WRONG (proof); statement vacuous
The proof uses exactly two inputs: β_0∈k(t)∖℘k(t) (Lemma 4.2 + Lemma 2.3 on P¹) and K(t)=K' (Cor 5.2). Both hold for the following data, which nevertheless satisfy (6.1):
- x_0:=s_1v_f∈K'. sympy (ghost-free, v_f²=v_f+f): ℘(x_0)=s_1²f+(s_1²+s_1)v_f.
- t:=s_0+℘(x_0)=s_0+s_1²f+(s_1²+s_1)v_f∉K (coefficient s_1²+s_1≠0), so K(t)=K', F_0:=k(t) has trdeg 1, F_0⊄K, KF_0=K'.
- β_0(T):=T∈k[T]; β_0∉℘k(t) (simple pole at ∞, Lemma 2.2).
Then β_0(t)=t=s_0+℘x_0: equation (6.1) is solvable with x_0∈K(v_f). So the argument of Prop 6.1, applied verbatim to this data, "proves" a false statement; the argument is invalid. (The statement of Prop 6.1 as a statement about witnesses is vacuously true because no witness exists, but that is the theorem being proved.)
Exact false sentences: (i) "Since t: P¹_{v_f}→P¹ is birational, it is unramified, so β_0(t) has a pole of the same odd order at the single point t⁻¹(u_0)" — there is no such map and no such point; (ii) "The constant s_0∈K is regular as a rational function of v_f, so β_0(t)−s_0 still has a pole of odd order" — false: at every valuation v of K'/k with v(t) odd and negative, v(t−s_0)=v(℘x_0) is even or ≥0, so v(s_0)=v(t) is odd and negative; s_0 has a pole exactly where the argument needs it not to. In the example this is forced because t−s_0=℘(x_0) has only even poles (Lemma 2.2 applied correctly).
Consequence: the first Witt coordinate can NEVER give a contradiction. For any witness the first coordinate of (4.1) is (s_0)_{K'}≡β_0(t), and the example shows that "t∉K, K(t)=K', β_0∉℘k(t)" is compatible with (6.1). A proof must use the second and third coordinates (or geometry, as ed2_equals_2.tex does); no parity argument on coordinate zero survives.

### (g) Theorem 6.2 — NOT PROVED by this note
Valid chain: Lemma 4.1 → (4.1) → Theorem 3.1 (F_0⊄K) → Lemma 5.1 (KF_0=K'). Then Cor 5.2 is wrong, so F_0=k(t) is not established, and Prop 6.1's proof is invalid even when F_0=k(t). The stated consequences ed^[2]=2 and d_1∈{3,4} therefore rest on nothing beyond the (correct) upper bounds Lemma 1.4 and [1, Prop 3.4]. Remarks 7.1–7.2 ("the order-8 first coordinate has an odd pole that birational change of the radical preserves") describe a mechanism that the example in (f) shows does not exist.

### (h) Lemma 2.3 — WRONG on curves of positive genus (true for P¹)
The "if" direction fails. Counterexample: k char 2, B: y²+xy=x³+a_6 with a_6≠0 (ordinary elliptic curve, j=1/a_6), F_0=k(B), β_0:=x. The only pole of x is O, of order 2 (even). Yet x∉℘F_0: with Y=y/x, F_0=k(x)(Y) where Y²+Y=x+a_6/x²; if w²+w=x then (w+Y+√a_6/x)²+(w+Y+√a_6/x)=√a_6/x, so F_0(w)=k(x)(Y,w') with w'²+w'=√a_6/x, and [x],[√a_6/x],[x+√a_6/x] are all nonzero in k(x)/℘ (simple poles at ∞, 0, {0,∞}), so w∉F_0. Moreover F_0(w)/F_0 is unramified everywhere (over x=∞ and x=0 the inertia group of the (Z/2)² extension of k(x) has order 2 and already surjects onto Gal(F_0/k(x)), elsewhere nothing ramifies): it is the étale double cover E^{(2)}→E of the ordinary curve, the nonzero class in H¹_ét(B,Z/2)=H¹(B,O)^{F=1}≠0. Any representative of a nontrivial unramified class has only even poles and at least one pole, so the lemma fails for every ordinary curve.
Where the proof breaks: "℘(√c u^{−m}) subtracts the top term ... iterating leaves a function with no poles". u is a global function with other zeros, so u^{−m} has other poles: for B above, u=x/y has a double zero at T=(0,√a_6), and ℘(y/x)=x+a_6/x² (sympy) trades the pole at O for a pole of order 4 at T; the next step trades it back: [x]=[a_6/x²]=[√a_6/x]=... The iteration does not terminate. On P¹, u=1/(T−a) has no other poles and the lemma is true — which is the only case the note uses (after the incorrect Cor 5.2). Note also that Riemann–Roch does not always provide a global function with prescribed leading term u^{−m} at P for small m (Weierstrass gaps), a second gap in the proof.
Relevance: since Cor 5.2 is wrong, a repaired argument would have to deal with F_0 of positive genus, where Lemma 2.3 is false; so the lemma's falsity is not cosmetic.

## 3. Overall verdict
Theorem 6.2 is NOT proved by this note. Established: Lemmas 1.2, 1.4, 4.1, 4.2, 5.1, Theorem 3.1, Fact 2.1, Lemma 2.2 (i.e. any witness K'=K(v_f) has f∉{0,s_0}+℘K, a descent field F_0⊄K with KF_0=K', and descent class β of exact order 8).
Irreparable within the note's method: Corollary 5.2 (F_0 rational, "t birational in v_f") has no valid proof and its premise K(B_K)=K' is dimensionally impossible; Proposition 6.1 is refuted as an argument by the explicit solution x_0=s_1v_f, t=s_0+℘x_0 of (6.1), which shows that coordinate zero alone can never yield the contradiction. The "parity mechanism" advertised in the abstract and Remarks 7.1–7.2 does not exist.
Fixable/minor: Corollary 1.3 (add Lemma 3.2), typo ℘(c²)→℘(c⁴) in Lemma 4.2, the citation label in Lemma 4.2. Lemma 2.3 is false in general (ordinary curves) and would have to be restricted to P¹ — but P¹ is precisely what the note cannot establish.
A correct proof needs the higher Witt coordinates and/or the geometry of the descent curve (as in ed2_equals_2.tex); nothing in the present note supplies that.
