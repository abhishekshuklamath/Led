# Remarks on Q1 (quadratic witnesses, d_1 = 2?) at (p,n) = (2,3) — from another chat

Quadratic extensions of K at (2,3). Yes, they are completely described: every separable quadratic extension of K = k(s₀,s₁,s₂) in characteristic 2 is Artin–Schreier, K(v_f) with v² + v = f, f ranging over H¹(K, Z/2) = K/℘K; purely inseparable ones change nothing (Prop 3.6 of the note). So Q1 ("is d₁ = 2?") is: does some f ∈ K/℘K have ed_k(τ_gen ⊗ K(v_f)) = 1? Known: f = s₀, s₁, s₂ all give exactly 2 (Thm 7.3 and Prop 3.9).

How the description helps — a dichotomy I can prove. Suppose K′ = K(v_f) is a witness, so τ_gen ⊗ K′ descends to k(B) ⊂ K′ for a curve B.

* Case A: k(B) ⊂ K. Then τ_gen and τ_B ⊗ K become isomorphic over K′, so they differ by the kernel of restriction, which by inflation–restriction is Hom(Z/2, Z/8) = {0, V²[f]}. Hence τ_gen ≡ τ_B ⊗ K + εV²[f] is defined over k(B)(f), of transcendence degree ≤ 2: ed(τ_gen) ≤ 2, Ledet(3) fails. (Also B is rational here, since k(B) ⊂ K.)
* Case B: k(B) ⊄ K. Then a descent of τ_gen ⊗ K′ to k(B) also descends its Z/4-truncation, so the truncation (s₀, s₁) must already drop to ed 1 over K(v_f). (I first thought this was contradictory via corestriction; it is not — f = s₁ shows the truncation does drop, since over K(v₁) it becomes [s₀].)

So: a quadratic witness either disproves Ledet outright (case A) or lies in the set 𝔉 := {f ∈ K/℘K : ed((s₀,s₁) ⊗ K(v_f)) = 1}, which is a (2,2)-question and hence in principle decidable with the tools we already have. Running the same dichotomy at level 2 shows 𝔉 contains the explicit family f ≡ (s − ℘x)₁ − b₁((s − ℘x)₀) for x ∈ W₂(K), b₁ ∈ k((s−℘x)₀) (the "level-2 case A"), plus whatever the level-2 case B allows — curves C with faithful Z/4 whose function field sits in k(z₀,z₁,s₂)(v_f) but not in k(z₀,z₁,s₂). Thm 7.3 is exactly the statement that for f = s₁ ∈ 𝔉 the top layer does not drop.

That gives a resolvable programme for Q1 in three finite steps: (1) determine 𝔉 exactly (a level-2 problem: classify the f for which the twisted curve E′ ⊗ K(s₂) acquires a free K(v_f)-point — Mordell–Weil of the quadratic twists E′^{(f)}: w² + w = u(u+1)(u+s₀) + s₁ + f over K, plus the level-2 case-B curves); (2) for f ∈ 𝔉, test the top Artin–Schreier layer with the Φ-operator / Prop 7.5 condition u(Q) ∉ K; (3) any success in step 2 is then a genuine d₁ = 2 witness, and by the dichotomy it would have to be a case-B witness, i.e. not immediately a counterexample to Ledet but a new invariant value. If step 1 shows 𝔉 is just the explicit level-2 case-A family (with case B empty), Q1 becomes a finite computation per x.
